# 交接文档 2026-10-03：Rich header 鉴定 + 双项目台账对账

## 背景

### 本项目（th10-re）

本项目是《东方风神录》(TH10) v1.00a 日文版的**匹配式逆向重建**（matching
decomp）：用原版时代的 MSVC 工具链从重建的 C/C++ 源码复现
`resources/th10.exe`，验收标准是编译产物与原版逐字节一致。验证设施已就位：
reccmp（`reccmp-project.yml`）+ objdiff（`objdiff.yml`）+ 2,519 个逐函数 .asm
参照 + Ghidra headless 脚本。

- 目标二进制：SHA-256 `2f14760b6fbbf57549541583283badb9a19a4222b90f0a146d5aa17f01dc9040`，
  487,936 字节，shift_jis，入口 `0x4537dc`（`config/target.toml`）。
- 验收等级序列：`unknown → typed → stubbed → implemented → object-matched →
  matched`（`TH10_RE_METHODOLOGY.md` / `TH10_PROGRESS_METRIC.md`）。
- 当前账本（`config/function-status.csv`）：958 implemented、16 object-matched、
  0 matched。
- 类型知识：src 83 个 struct + IDB 类型库 75 个结构体（10 轮结构体化，修过
  比较常量/遍历顺序/双解引用等语义错误）。
- 分母（`config/crt-lib-map.csv`，IDA+FLIRT）：**游戏代码 1,417 函数 /
  293,738 字节**；库代码 496 函数 / 54,369 字节（链接正确版本的 CRT/DX 库
  即得，不重建）。
- 独家参照：th06/th07/th08 参照二进制（`references/`），同引擎血统。

### 为什么合并

两边互补、重叠极小：我们持有**语义资产**（958 implemented、结构体库、系列
参照），他们持有 **codegen 资产**（280 个已验证 exact 函数、正确的工具链
鉴定、构建图方法论、验证脚本）。合并工作量评估：合并本体 2-4 周；全部游戏
函数 object-matched 约 6-12 个月；linked-PE 逐字节一致（含构建图攻坚）合计
半年到一年半。

### 1. Rich header 工具链鉴定（完成，结论钉死）

独立解析 DOS stub Rich header（key `0x3152a748`，DanS@0x80，Rich@0x108）：
cl 家族 232 个对象中 229 个 build=6030（C=131、C++=15、LTCG-C++=52、
MASM=1、IDL=33），**build=3077 对象为 0**。杂项 2179/4035/3052/9178 为链接
期 DLL 输入，非编译主体。

**裁决：原版编译器 = cl 13.10.6030（VC7.1 SP1），链接器 7.10.6030。
`target.toml` 原钉的 Toolkit 2003 13.10.3077 是错的**——与 N0zoM1z0 断言及
131/15/52 三个数字完全吻合。证据：`docs/EVIDENCE-RICH-HEADER.md`，
脚本：`scripts/rich_header_fingerprint.py`（verdict 行的对象数统计有小
cosmetic bug，结论不受影响）。
